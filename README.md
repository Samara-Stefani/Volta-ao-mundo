# 🌍 Volta ao Mundo - Egito 📜🐫
## https://samara-stefani.github.io/Volta-ao-mundo/
## 📌 Sobre o Projeto
O **Volta ao Mundo** é um projeto acadêmico desenvolvido com o objetivo de apresentar informações sobre diferentes países de maneira interativa. 

Nesta versão, o país explorado é o **Egito**, trazendo conteúdos sobre sua cultura, culinária, pontos turísticos e informações gerais.

O site foi criado para prazer uma experiência visual agradável, permitindo que os usuários conheçam melhor um dos países mais históricos do mundo.

---

## 🎯 Objetivos
- Apresentar informações sobre o Egito de forma clara e organizada
- Explorar aspectos culturais do país
- Destacar os principais pontos turísticos
- Fornecer dados gerais importantes
- Desenvolver habilidades em desenvolvimento web com o framework Bootstrap
